## Week 1: Python Basics for AI

### Learning Activities

During the first week, the basics of Python libraries commonly used in Artificial Intelligence and Machine Learning were studied. The main focus was on NumPy, Matplotlib, and TensorFlow/Keras.
NumPy was explored for working with numerical data and arrays. Matplotlib was used for creating graphs and visualizing data. The basic concepts of TensorFlow and Keras were studied to understand how deep learning and CNN models can be developed.

### Python Practice

Several Python programs were developed for basic chest X-ray dataset exploration:

1. Reading image files from class folders.
2. Counting the number of images in each class.
3. Creating a class distribution graph.
4. Displaying multiple X-ray images in a grid.

These exercises provided initial experience with handling image datasets and visualizing data using Python.

### Reading Activity

One survey paper related to Explainable AI in Medical Imaging was studied. The paper helped in understanding the importance of interpretability in medical AI systems and how explainability methods can help explain the decisions made by deep learning models.
