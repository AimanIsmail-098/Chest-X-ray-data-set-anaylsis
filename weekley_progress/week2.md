### Task 1: Dataset Analysis

A detailed analysis of the chest X-ray dataset was performed. The dataset contained 513 images in total, including 257 Normal images and 256 Pneumonia images.

The class imbalance ratio was approximately 1.0:1, showing that the dataset was well balanced. Image dimensions were also analyzed, and no corrupted images were detected.

### Task 2: Data Visualization

- Class distribution graph

These visualizations helped provide a better understanding of the structure and characteristics of the dataset.

### Task 3: Experimental Design

The initial experimental design for the future CNN-based classification model was defined.

The planned image input size was:

- 224 × 224 pixels
- Grayscale image input

The dataset will be divided into training, validation, and testing subsets for model development and evaluation.

The initial CNN architecture will be evaluated for classifying chest X-ray images into Normal and Pneumonia classes.

The planned performance metrics are:

- Accuracy
- Precision
- Recall
- F1-score
