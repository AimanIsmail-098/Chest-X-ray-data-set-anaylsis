Task 1: Model Evaluation

The trained deep learning models, including CNN, MobileNetV2, and ResNet50, were evaluated using the same chest X-ray test dataset. Test accuracy, test loss, and other evaluation metrics were calculated to measure the performance of each model.

The evaluation results were:

CNN Accuracy: 75.48%
MobileNetV2 Accuracy: 87.18%
ResNet50 Accuracy: 63.78%

These results were used for further comparison and performance analysis.

Task 2: Model Comparison

A detailed comparison of the three models was performed using multiple evaluation metrics.

The comparison included:

Accuracy
Precision
Recall
F1-score
Training Time
Number of Parameters

The comparison showed that MobileNetV2 achieved the highest overall accuracy and F1-score, making it the best-performing model among the three evaluated architectures.

Task 3: Performance Visualization

Different visualizations were generated to analyze the learning behavior and classification performance of the models.

The generated visualizations included:

Accuracy Curves
Loss Curves
Confusion Matrices
ROC Curves

These visualizations provided a clear understanding of model convergence, prediction performance, and classification capability on the chest X-ray dataset.

Task 4: Comparative Analysis

A comprehensive comparative analysis of the evaluated models was carried out to identify the most suitable model for pneumonia detection.

The analysis compared the strengths and limitations of CNN, MobileNetV2, and ResNet50 based on their evaluation metrics and graphical results.

The study concluded that MobileNetV2 was the best-performing model because it achieved the highest accuracy (87.18%), balanced precision and recall, and the highest F1-score while maintaining efficient computational performance. The findings were summarized in the final comparison report and prepared for research documentation.
